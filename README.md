# ❝ Daily Inspiration (Quotes)

**A Minimalist Source of Wisdom & Motivation**

![Version](https://img.shields.io/badge/version-1.0-blueviolet)
![Status](https://img.shields.io/badge/status-live-success)

**Daily Inspiration** is a functional, glassmorphism-styled web app that delivers curated quotes with ambient background animations.

🔗 **Live Demo:** [https://thegem001.github.io/Quotes/](https://thegem001.github.io/Quotes/)

---

## ✨ Features

* **Glassmorphism UI:** Translucent card layout with animated ambient backgrounds.
* **Auto-Refresh:** Fetches a new quote every 60 seconds with a visual progress bar.
* **Smart Sharing:** Integrated Web Share API and one-click clipboard copying.
* **Hybrid Data:** Fetches from `dummyjson.com` with a local fallback for offline use.

---

## 💻 Tech Stack

* **Frontend:** HTML5, Vanilla JS (ES6+), Tailwind CSS
* **Icons:** Phosphor Icons
* **Typography:** DM Serif Display & Inter

---

## ⚙️ Quick Start

1. **Clone:** `git clone https://github.com/thegem001/Quotes.git`
2. **Run:** Open `index.html` in any browser (Live Server recommended for API stability).
